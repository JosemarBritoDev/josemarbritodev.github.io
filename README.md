# 🚀 BritosCode.tech — Portfólio & Vitrine de Soluções SaaS

Portal institucional e portfólio oficial da **BritosCode Tecnologia**, desenvolvido por **Josemar Brito** para apresentar plataformas SaaS em produção, sistemas ERP sob medida, automações em Python e serviços de infraestrutura de redes e cloud.

🌐 **Acesse online:** [josemarbritodev.github.io](https://josemarbritodev.github.io)

---

## ✨ Destaques do Projeto

- **Design Dark Mode & Neon Purple:** Identidade visual moderna em preto profundo (`#06040a`) com acentos em roxo neon (`#8b5cf6` / `#c084fc`), efeitos de *glassmorphism* e responsividade completa para desktop e dispositivos móveis.
- **Vitrine de Soluções em Produção:** Apresentação detalhada dos sistemas desenvolvidos, stacks utilizadas e links diretos para ambientes ativos.
- **BritosBot (Consultor Virtual Interativo):** Assistente virtual em SVG animado nativamente (sem dependências externas), com base de conhecimento estruturada por sistema (*O que faz*, *Como foi criado* e *Como contratar*), efeito de digitação em tempo real e integração direta com WhatsApp e sites oficiais.
- **Zero Dependências de Build:** Arquitetura leve e ultrarrápida construída em HTML5, CSS3 puro e JavaScript Vanilla, ideal para hospedagem estática no GitHub Pages.
